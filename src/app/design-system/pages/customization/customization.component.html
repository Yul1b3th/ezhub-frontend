Personalización

En esta sección, aprenderás cómo personalizar el Design System utilizando variables, funciones y mixins.

Variables

Las variables permiten definir valores reutilizables en todo el sistema de diseño. A continuación se presentan las principales variables utilizadas:

Tipografías


      // Tipografías
      $font-family: "BeVietnamPro", sans-serif;

Tamaños de fuente


      // Tamaños de fuente
      $font-sizes: (
        xs: 0.75rem,
        sm: 0.875rem,
        base: 1rem,
        lg: 1.125rem,
        xl: 1.25rem,
        "2xl": 1.5rem,
        "3xl": 1.875rem,
        "4xl": 2.25rem,
        "5xl": 3rem,
      );

Alturas de línea


      // Alturas de línea
      $line-heights: (
        xs: 1rem,
        sm: 1.25rem,
        base: 1.5rem,
        lg: 1.75rem,
        xl: 2rem,
      );

Breakpoints


      // Breakpoints
      $breakpoints: (
        xs: 0,
        sm: 576px,
        md: 768px,
        lg: 992px,
        xl: 1200px,
        xxl: 1400px,
      );

Espaciados


      // Espaciados
      $spacing: (
        xs: 0.25rem,
        sm: 0.5rem,
        md: 1rem,
        lg: 2rem,
        xl: 4rem,
      );

Colores principales


      // Colores principales
      $colors: (
        "primary": #7fe6c0,

        "gray": #d1d1d1,

        "light": #e5e5e5,

Mapas de colores expandidos


  // Mapas de colores expandidos
  // Estos mapas se utilizan para definir colores de fondo predeterminados y
  // colores invertidos, facilitando la implementación de temas claros y oscuros.
  $backgrounds: map.merge(
    $colors,
    (
      "default": map.get($colors, "gray-light"), // Color de fondo predeterminado
      "inverted": map.get($colors, "dark"), // Color de fondo invertido para temas oscuros
    )
  );

Los mapas de colores expandidos permiten definir colores de fondo predeterminados e invertidos, lo que facilita la implementación de temas claros y oscuros en el sistema de diseño.

Funciones

Las funciones en Sass permiten reutilizar lógica y cálculos en todo el sistema de diseño. A continuación se presentan las principales funciones utilizadas:

Función genérica para obtener valores de un mapa

    
      // Función genérica para obtener valores de un mapa
      @function get-value-from-map($map, $key) {
        @if map.has-key($map, $key) {
          @return map.get($map, $key);
        } @else {
          @error "La clave {{$key}} no existe en el mapa proporcionado.";
        }
      }

Esta función permite obtener valores de un mapa dado una clave específica. Es útil para acceder a valores definidos en mapas como colores, tamaños de fuente, etc.

Función para obtener un tamaño de fuente

    
      // Función para obtener un tamaño de fuente
      @function get-font-size($size-name) {
        @return get-value-from-map($font-sizes, $size-name);
      }

Esta función devuelve el tamaño de fuente correspondiente a un nombre de tamaño específico.

Función para obtener una altura de línea

    
      // Función para obtener una altura de línea
      @function get-line-height($size-name) {
        @return get-value-from-map($line-heights, $size-name);
      }

Esta función devuelve la altura de línea correspondiente a un nombre de tamaño específico.

Función para obtener un breakpoint

    
      // Función para obtener un breakpoint
      @function get-breakpoint($size-name) {
        @return get-value-from-map($breakpoints, $size-name);
      }

Esta función devuelve el valor del breakpoint correspondiente a un nombre de tamaño específico.

Función para obtener un espaciado

    
      // Función para obtener un espaciado
      @function get-spacing($size-name) {
        @return get-value-from-map($spacing, $size-name);
      }

Esta función devuelve el valor de espaciado correspondiente a un nombre de tamaño específico.

Función para obtener un color

    
      // Función para obtener un color
      @function get-color($color-name) {
        @return get-value-from-map($colors, $color-name);
      }

Esta función devuelve el valor del color correspondiente a un nombre de color específico.

Función para obtener un color de fondo

    
      // Función para obtener un color de fondo
      @function get-background($background-name) {
        @return get-value-from-map($backgrounds, $background-name);
      }

Esta función devuelve el valor del color de fondo correspondiente a un nombre de fondo específico.

Función para convertir colores a HSL

    
      // Función para convertir colores a HSL
      @function to-hsl($color) {
        @return hsl(
          color.channel($color, "hue", $space: hsl),
          color.channel($color, "saturation", $space: hsl),
          color.channel($color, "lightness", $space: hsl)
        );
      }

Esta función convierte un color a su representación en HSL (Hue, Saturation, Lightness).

Función para convertir colores a HSLA con transparencia

    
      // Función para convertir colores a HSLA con transparencia
      @function to-hsla($color, $alpha) {
        @return hsla(
          color.channel($color, "hue", $space: hsl),
          color.channel($color, "saturation", $space: hsl),
          color.channel($color, "lightness", $space: hsl),
          $alpha
        );
      }

Esta función convierte un color a su representación en HSLA (Hue, Saturation, Lightness, Alpha) con un valor de transparencia.

Mixins

Los mixins en Sass permiten reutilizar bloques de código CSS en todo el sistema de diseño. A continuación se presentan los principales mixins utilizados:

Mixin para aplicar márgenes y rellenos


  // Mixin para aplicar márgenes y rellenos
  @mixin spacing($property, $size) {
    #{$property}: get-spacing($size);
  }

Este mixin permite aplicar márgenes y rellenos de manera dinámica utilizando las variables de espaciado definidas.

Mixin para manejar márgenes y rellenos de manera abreviada


  // Mixin para manejar márgenes y rellenos de manera abreviada
  @mixin padding-margin($type, $size) {
    #{$type}-top: get-spacing($size);
    #{$type}-right: get-spacing($size);
    #{$type}-bottom: get-spacing($size);
    #{$type}-left: get-spacing($size);
  }

Este mixin permite manejar márgenes y rellenos de manera abreviada.

Mixin para aplicar colores generales


  // Mixin para aplicar colores generales (textos, fondos, bordes)
  @mixin color($property, $color-name) {
    #{$property}: get-color($color-name);
  }

Este mixin permite aplicar colores a propiedades específicas como texto, fondo y bordes.

Mixin para aplicar colores de fondo


  // Mixin para aplicar colores de fondo
  @mixin background($background-name) {
    background-color: get-background($background-name);
  }

Este mixin permite aplicar colores de fondo utilizando los mapas de colores expandidos.

Mixin para tipografía


  // Mixin para tipografía: tamaño de fuente, altura de línea, peso y margen inferior
  @mixin typography(
    $font-size,
    $line-height: base,
    $font-weight: normal,
    $margin-bottom: null,
    $color: null
  ) {
    font-size: get-font-size($font-size);
    line-height: get-line-height($line-height);
    font-weight: $font-weight;
    @if $margin-bottom != null {
      margin-bottom: get-spacing($margin-bottom);
    }
    @if $color != null {
      color: get-color($color);
    }
  }

Este mixin permite aplicar estilos tipográficos como tamaño de fuente, altura de línea, peso, margen inferior y color.

Mixin para aplicar colores específicos en modos claro y oscuro


  // Mixin para aplicar colores específicos en modos claro y oscuro
  @mixin apply-color($light-color, $dark-color) {
    color: get-color($light-color);
    @media (prefers-color-scheme: dark) {
      color: get-color($dark-color);
    }
  }

Este mixin permite aplicar colores específicos para modos claro y oscuro.

Mixin para establecer una fuente específica


  // Mixin para establecer una fuente específica
  @mixin font-family($family: $font-family) {
    font-family: $family;
  }

Este mixin permite establecer una fuente específica.

Mixin para aplicar estilos en diferentes breakpoints


  // Mixin para aplicar estilos en diferentes breakpoints
  @mixin media-breakpoint-up($size) {
    @media (min-width: get-breakpoint($size)) {
      @content;
    }
  }

Este mixin permite aplicar estilos en diferentes breakpoints.

Mixin para bordes redondeados


  // Mixin para bordes redondeados
  @mixin border-radius($radius) {
    border-radius: $radius;
  }

Este mixin permite aplicar bordes redondeados.

Mixin para sombras


  // Mixin para sombras
  @mixin box-shadow($x, $y, $blur, $spread: 0, $color: rgba(0, 0, 0, 0.25)) {
    box-shadow: $x $y $blur $spread $color;
  }

Este mixin permite aplicar sombras a los elementos.

Mixin para controlar la opacidad de un color


  // Mixin para controlar la opacidad de un color
  @mixin opacity($color, $opacity) {
    background-color: rgba(
      color.channel($color, "red"),
      color.channel($color, "green"),
      color.channel($color, "blue"),
      $opacity
    );
  }

Este mixin permite controlar la opacidad de un color.

Mixin para alinear elementos con Flexbox


  // Mixin para alinear elementos con Flexbox
  @mixin flex-container($direction: row, $justify: center, $align: center) {
    display: flex;
    flex-direction: $direction;
    justify-content: $justify;
    align-items: $align;
  }

Este mixin permite alinear elementos utilizando Flexbox.

Mixin para items de flex


  // Mixin para items de flex
  @mixin flex-item($grow: 0, $shrink: 1, $basis: auto) {
    flex-grow: $grow;
    flex-shrink: $shrink;
    flex-basis: $basis;
  }

Este mixin permite definir propiedades de flex para los elementos.

Mixin para transiciones suaves


  // Mixin para transiciones suaves
  @mixin transition($properties, $duration: 0.3s, $timing-function: ease-in-out) {
    transition: $properties $duration $timing-function;
  }

Este mixin permite aplicar transiciones suaves a los elementos.

Mixin para aplicar un gradiente


  // Mixin para aplicar un gradiente
  @mixin gradient($start-color, $end-color, $direction: to right) {
    background: linear-gradient($direction, $start-color, $end-color);
  }

Este mixin permite aplicar un gradiente a los elementos.
